## 카카오싱크 기반 이벤트 참여 인증 간소화

기존 이벤트는 사용자가 휴대폰 번호를 직접 입력하고 인증해야 참여할 수 있어, 신규 사용자가 이벤트에 진입하기까지 여러 단계를 거쳐야 했습니다.

이벤트 참여 인증 플로우를 카카오싱크 기반으로 전환해, **카카오 인증만으로 이벤트에 필요한 사용자 정보를 수집하도록 구성**했습니다. 웹앱과 이벤트 서비스에 이를 적용해 기존 휴대폰 번호 인증보다 참여 단계를 줄였습니다.

## 퍼머링크 도입을 통한 iOS 복귀 병목 개선

iOS에서는 카카오 인증을 마친 뒤 브라우저로 자동 복귀하지 않아, 인증을 완료한 사용자도 이벤트 참여를 이어가지 못하고 이탈하는 문제가 있었습니다.

이를 해결하기 위해 **카카오싱크와 연계된 퍼머링크 복귀 방식을 제안·적용**했습니다. 인증이 끝나면 외부 브라우저가 아닌 카카오톡 인앱뷰로 이동하도록 강제해, 사용자가 브라우저로 직접 이동해야 하는 단계를 없앴습니다.

## 성과

퍼머링크 적용 이후 인증부터 결과 화면까지의 흐름이 이어지면서 **친구 초대 이벤트 참여 성공률이 32%에서 38%로 6%p 상승**했습니다. 휴대폰 번호 입력을 카카오싱크 인증으로 대체해 신규 사용자의 참여 단계도 줄였습니다.
