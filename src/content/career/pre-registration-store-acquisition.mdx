공공데이터와 외부 데이터를 기반으로 미가맹 매장을 앱에 먼저 노출하고, 이를 운영·관리할 수 있는 백오피스와 사용자 참여 기능을 개발했습니다. 사용자의 전화 주문과 영수증 리뷰를 통해 미가맹 사장님에게 패스오더를 알리고, 축적된 참여 데이터를 영업 조직의 후속 접근으로 연결하는 매장 획득 프로젝트입니다.

## 미가맹 매장 노출 및 사용자 참여 기능 개발

사용자가 주변의 미가맹 매장을 쉽게 발견하고 참여할 수 있도록 매장 카드와 상세 화면, 주변 매장 탐색, 매장 정보 제보 기능을 구현했습니다. 사전등록 매장과 일반 입점 매장을 구분할 수 있도록 상태와 배지 정보를 제공하고, 다양한 경로에서 미가맹 매장을 발견할 수 있도록 노출 영역을 확장했습니다.

전화 주문 이후에는 사용자가 영수증 리뷰까지 자연스럽게 이어갈 수 있도록 인앱 웹뷰에서 외부 리뷰 서비스를 연동했습니다. 외부 페이지 변경에도 앱 재배포 없이 대응할 수 있도록 **Firebase Remote Config 기반으로 연동 로직을 관리**해 문제가 발생하면 원격에서 수정하거나 비활성화할 수 있도록 구성했습니다.

## 매장 획득 데이터·운영 백오피스 구축

사전등록 매장의 상태와 사용자 반응을 운영자가 한눈에 확인할 수 있도록 전용 백오피스를 구축했습니다. 매장별 전화 시도와 성공 건수 등 **사용자 참여 성과를 조회할 수 있는 화면**을 만들고, 운영 기간과 상태, 리워드 등급에 따라 매장을 필터링할 수 있도록 구성했습니다.

반복되는 매장 정보와 운영 상태는 카드형 UI로 정리하고, 목록과 로딩 영역은 공통 컴포넌트로 분리해 기능이 추가돼도 동일한 구조를 재사용할 수 있도록 했습니다.

이를 통해 파지팀과 영업 조직이 단순히 미가맹 매장 목록을 확인하는 데 그치지 않고, **사용자 반응이 높은 매장을 우선적으로 선별해 후속 영업에 활용할 수 있는 운영 구조**를 만들었습니다.

## 성과

미가맹 매장의 사전 노출부터 사용자 참여, 운영 데이터 확인, 후속 영업까지 이어지는 흐름을 구축해 **매장 도입률 5% 이상을 달성**했습니다.

공공데이터로 확보한 매장 정보를 단순 노출하는 데 그치지 않고, **사용자 참여 → 사장님의 서비스 인지 → 영업 조직의 후속 접근**으로 이어지는 신규 매장 획득 채널로 확장했습니다.

**사용 기술:** React, TypeScript, Firebase Remote Config, WebView
